How the files are organized

The dataset is one folder per deployment site, and inside it one folder per recording session. The two sites are laid out a little differently, so each has an example below. The files themselves are shared after a signed data use agreement. Request access.

Astor Place

One folder per session day, named by date. The session of September 26, 2022 is shown as the example. Other sessions follow the same idea, though folder names and nesting vary a little from day to day.

  • Astor_Place/
    • 2022-09-21-astor-place/
    • 2022-09-26-astor-place/
      • onboard_camera/ 360° video from the camera on each robot
        • 202209-26-landfill.mp4
        • 202209-26-recycle.mp4
      • clips/ short clips cut from the session video
        • clip1.mp4
        • clip2.mp4
        • …
    • 2022-09-28-astor-place/
    • 2022-10-06-astor-place/
    • 2022-10-12-astor-place/
    • updated_clip_log_gsheet.xlsx annotations, one sheet per session

Albee Square

Three folders per session day, named month-day: one for each robot and one for interviews. July 12, 2023 is shown as the example.

  • Albee_Square/
    • 7-6-…/, 7-7-…/, 7-11-…/, 7-14-…/ same three folders for each day
    • 7-12-landfill/ the landfill robot
      • VID_20230110_180712_00_001.mp4
      • VID_20230110_191735_00_002.mp4
    • 7-12-recycle/ the recycling robot
      • VID_20230504_143828_00_001.mp4
      • VID_20230504_154852_00_002.mp4
    • 7-12-interview/ interviews recorded that day
    • Trashbot Video Annotations updated.xlsx annotations, one sheet per robot per day

Reading the file names

Some video files keep the name the camera gave them: VID_, then the date and time on the camera's clock, then a part number. At Albee Square the camera clocks were not set, so the date in a file name does not match the day of recording. Go by the folder name for the session date.

The annotation sheets give the start and end time of each interaction within the video. The Albee Square sheet also names the video file for each one.
